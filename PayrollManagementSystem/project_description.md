# Payroll Management System

This repository is a command-line payroll and employee tracking exercise. Administrators manage employee data and HR accounts, HR staff maintain the employee payroll, and users can view the payroll data and confirm payments. Each implementation stores its users and payroll in small CSV files so the program can be used without a database.

The deliberately flawed programs are intended for beginner debugging practice. Their companion bug keys explain the expected behaviour after a learner has investigated each implementation.
