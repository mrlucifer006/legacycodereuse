# Hotel Management System

This repository is a command-line hotel management and room booking exercise. Administrators manage room catalogs and receptionist accounts, receptionists maintain the room information, and customers browse rooms, build a booking, and receive a checkout summary. Each implementation stores its users and rooms in small CSV files so the program can be used without a database.

The deliberately flawed programs are intended for beginner debugging practice. Their companion bug keys explain the expected behaviour after a learner has investigated each implementation.
