# Hotel Management System

## Overview

The Hotel Management System is a simple Python-based application designed to manage basic hotel operations. It provides functionality for managing customers, rooms, food orders, and billing.

This repository is included as a legacy codebase for the **Legacy Code Reuse** competition. The original project has been preserved as the base code for further analysis and controlled logical-bug injection.

## Features

- Customer information management
- Room booking
- Room type selection
- Room rent calculation
- Restaurant / food ordering
- Food bill calculation
- Additional service charges
- Total bill calculation
- Checkout and billing

## Technology Used

- Python
- Python Standard Library
