# Student Course Management System

This project is a file-backed command-line application for managing a small course catalog. It uses three roles.

Admins sign in to create teacher accounts and manage the complete course catalog. Teachers sign in to add, update, and view courses. Students do not need an account: they can browse courses, build an enrollment cart, review charges, and confirm checkout.

The application stores credentials and course information in simple CSV files. Each language folder contains an equivalent two-source-file implementation and a debugging exercise with intentionally planted logical defects. The source files compile or parse successfully; the challenge is to trace the unexpected behavior in the running application.
