# Food Order Management System

This repository is a command-line food catalogue and ordering exercise. Administrators manage menu items and delivery staff accounts, delivery staff maintain the menu, and customers browse food, build an order, and receive a checkout summary. Each implementation stores its users and menu in small CSV files so the program can be used without a database.

The deliberately flawed programs are intended for beginner debugging practice. Their companion bug keys explain the expected behaviour after a learner has investigated each implementation.
